# KINGMAKER — 36-CHAPTER PRODUCTION MATRIX
**Purpose:** scene-production handoff map, not a claim these chapters are implemented.

## Canon and scope
The six-act, 36-chapter spine is defined by `docs/03_STORY_CAMPAIGN_ARCHITECTURE_V1.md`. Chapter descriptions and visual motifs below are **working production interpretations**, not replacements for that document. **Chapters 1–6 already have scaffolded playable content; Chapters 7–36 are planned.** Need context-aware branching and reusable art contracts before scaling.

## Universal chapter production packet
For **each chapter**, before it can move from `todo`:
1. **Synopsis / intent:** player goal, stakes, location, access rights, tense timing.
2. **Scene cards:** scene IDs, act/chapter, location and visual mode, actor owners, reading budget, linked canon, preconditions.
3. **Information graph:** claims, sources, evidence independence, unknowns, what the player could infer at that point.
4. **Action graph:** investigate/contact/verify/delegate/decide, costs, possible follow-up, reversible vs irreversible.
5. **Actors and consequences:** incentives, dialogue states, promises, immediate response, delayed callbacks, visible externality.
6. **Mechanism mapping:** intended strategic competencies, optional debrief, fairness review.
7. **Presentation and assets:** approved location/portrait/prop, accessibility and performance variants.
8. **Tests:** positive/negative paths, save/replay, source/knowledge projection, actor continuity, mobile smoke.
9. **Handoff evidence:** code/content PR, test notes, provenance and signoff.

Each chapter expands to 3–5 principal scenes only if pacing research supports it. Avoid treating 36×3 as a fixed content contract; gameplay actions and scene variability can alter time substantially.

## Wave plan and integration gates
- **Proof wave (Ch 1–3):** test the moment-to-moment experience, source interpretation, character attachment, and return impulse. Primary tasks KM-018–035.
- **Act I polish (Ch 4–6):** upgrade existing playable material to gold fidelity after engine integration. Primary KM-047–053.
- **Expansion waves (Acts II–VI):** each six-chapter wave should follow **mechanic proof → narrative packets → art pack → implementation → branching tests → player gate**; phase workstreams P06–P10.
- **Cross-act dependencies:** source confidence and time/attention (I) → staff/projects (II) → coalitions/agenda (III) → adversarial belief model (IV) → crisis dependencies (V) → legacy/causal archive (VI).
- **Carryovers required in QA:** government configuration, procedural timing, public narratives, promises, relationships, NSO personalization, Silas observations, project outcome, crisis exposure, succession capacity.

## Production risks
Canon title is not an implementation task. A complete text scene is not a gameplay system. A portrait is not a character with memory. A state scalar is not a credible causal model. Do not mark a chapter gold without **art, interaction, conditional consequence, continuity and device tests**.
