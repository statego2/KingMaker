# KINGMAKER — High-Level Design Preproduction

This directory is intentionally isolated from implementation.

It defines the high-level creative direction, game feel, information architecture, visual system and asset language for KINGMAKER: The Game of Judgment. It does not connect assets to runtime code, alter engine contracts or modify campaign logic.

## Core thesis

KINGMAKER should feel like a premium statecraft thriller in your hand.

The player is not collecting generic points. They are gradually learning to see the hidden structure behind institutions, relationships, information and power.

The interface must make that fantasy tangible.

## Creative identity

- Genre: strategic narrative RPG / political systems thriller
- Setting: Republic of Lydria, 2032
- Fantasy: becoming indispensable without becoming simplistic or omnipotent
- Emotional progression: curiosity → tension → competence → influence → burden → judgment → legacy
- Visual proposition: statecraft noir
- Interaction proposition: dossiers, briefings, maps, relationship networks, decision sheets and living consequences
- Anti-proposition: not cyberpunk, not casino mobile UI, not a spreadsheet skin, not a quiz app, not parody politics

## Concept assets

The assets/concepts directory contains non-runtime SVG direction studies. They are reference material only. The main project AI or implementation team can later convert, redraw or connect them.

## Design rule

Every visual element should help the player answer at least one of these questions:

- What is happening?
- Who matters?
- What changed?
- What do they believe?
- What do I know?
- What am I risking?
- What can I influence?
- What will persist after this decision?

If an element answers none of them, it is decoration and should justify its cost very carefully.
